Padrões:
- **Gancho** nos 2 primeiros segundos: dor concreta do dono de negócio local, ou curiosidade. Sempre entregue 3 variações (A/B/C) para teste.
- **Estrutura de reels (15–25s):** gancho → problema (3 dores curtas) → demonstração do serviço → resultado → "Comenta PALAVRA".
- **Um serviço por post.** Fale para quem (lanchonete, barbearia…) e qual resultado.
- **Legenda:** 1ª linha = gancho; corpo curto; CTA; 5–10 hashtags locais (#campinagrande #paraiba + nicho).
- Série recorrente: "Digitalizando CG · ep. N".
- Para cases reais, peça confirmação do Mathias antes de citar o cliente.
