# Respostas automáticas por palavra-chave (ManyChat)

Regra: comentário contém a palavra → resposta pública curta + DM com botão.
Respostas públicas (alternar): "Te mandei no direct! 📩" · "Chegou aí no direct 👀" · "Enviado! Dá uma olhada no direct".

| Palavra (e sem acento) | DM | Botão → link |
|---|---|---|
| PROJETO | Oi! 👋 Aqui estão alguns projetos da BIOS rodando de verdade. Quer um pro seu negócio? | Ver projetos → [LINK DO SITE/PORTFÓLIO] |
| CARDÁPIO / CARDAPIO | Oi! Veja como funciona o cardápio digital: o cliente escolhe e o pedido chega pronto no seu WhatsApp. | Ver exemplo → https://emillylanches.com.br |
| SITE | Oi! Esses são sites que a BIOS fez. Me conta seu ramo que eu te passo um orçamento. | Ver sites → [LINK] |
| AGENDA | Oi! Agendamento online 24h com lembrete no WhatsApp. Seu negócio é barbearia, salão, clínica…? | Ver como funciona → [LINK] |
| SISTEMA | Oi! Vendas, estoque e caixa num painel só. Quer uma demonstração rápida? | Quero demonstração → [LINK WHATSAPP] |
| AUTO | Viu? Essa mensagem é automática 😉 A gente monta isso pro seu negócio. | Quero automatizar → [LINK WHATSAPP] |

Pré-requisitos: conta profissional no Instagram + "Permitir acesso às mensagens" ligado em Ferramentas conectadas.
